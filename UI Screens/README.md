# UI Screens

Exported from the active Sports Hub / MVP Figma page.

- **123 verified PNGs**: 61 desktop and 62 mobile.
- Full-length PNG exports. Figma caps the longest edge at 4096 px, so taller mobile screens are proportionally reduced; other screens retain their frame size. The manifest records source and output dimensions.
- Open **index.html** for a visual gallery. **screens.csv** and **export-manifest.json** record dimensions, file sizes and source Figma links.

## Folder structure

Both **01 Desktop** and **02 Mobile** contain:

1. **01 Public Screens**: homepage, discovery, club, session details, login/signup; mobile also includes its menu.
2. **02 Student Journey**: activities, payment/receipt, confirmation, rejection/resubmission, cancellation, refund status and static Inbox preview.
3. **03 Club Manager**: draft/publication, participants, payment decisions, closure/cancellation and refund/withdrawal records.
4. **04 States and Errors**: full, closed, started, cancelled, expired, invalid submission and empty states.

5. **05 Design Handoff**: the current desktop/mobile implementation guides.

Archived pages, reusable components and source assets are excluded. These are static images of the approved synthetic prototype, including demo payment details and AI-generated sports photography.
